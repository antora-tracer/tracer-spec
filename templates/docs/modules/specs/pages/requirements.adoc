= Requirements
:traceability-links: true

Requirements describe observable obligations. Use `level=product`, `level=component`, or `level=software`; detailed requirements link to the broader requirement they refine.

Group requirements by architectural container, then by functional area.
Each area is one grouped partial named `<level>-<area>.adoc`; an area present at two levels keeps one heading with the broader level first.
Take the containers from the xref:architecture.adoc[Building Block View]; add a new area include under the container its requirements belong to.

== <Container>

Give the container a one-line description, then one `===` area heading per functional area, each with a single include line, for example `include::partial$requirements/component-workflow-cli.adoc[]`.

== Requirement template

[source,asciidoc]
----
[#REQ-NNN, item, role=requirement, level=component, status=draft, title="<observable obligation>"]
--
The system SHALL <observable behavior>.

refines:REQ-PARENT[]
tracer:links[]
--
----
