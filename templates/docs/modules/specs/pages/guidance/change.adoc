= Change

A change is the entry point of the workflow.
It records rationale, outcome, and out-of-scope fields, and links to the requirements it addresses and the decisions it records.

Status: `proposed` → `refined` → `accepted` → `implemented` → `verified` → `closed` · `rejected`.

An implementation change may carry optional shared external `externalId=<existing-item-id>` metadata in its item header. Local changes may omit it when they address applicable approved requirements.

An accepted change must address at least one requirement.
