= Decisions
:traceability-links: true

Use `decision` items for domain and business choices. Use `adr` items for costly-to-reverse software architecture choices.

[source,asciidoc]
----
[#DEC-NNN, item, role=decision, status=proposed, title="<decision>"]
--
Context:: Why this decision is needed.
Options:: Alternatives with advantages and disadvantages.
Decision:: What was decided.
Rationale:: Why this option was selected.
Consequences:: What follows.

recorded_by:CHG-NNN[]
tracer:links[]
--
----



== Accepted

Add each accepted decision's `include::partial$decisions/<file>.adoc[]` line below.
An `accepted` decision governs the current workflow.

== Proposed

Add each not-yet-in-force decision's `include::partial$decisions/<file>.adoc[]` line below.
A `proposed` decision is recorded but does not govern yet; move it to Accepted when it takes effect.
