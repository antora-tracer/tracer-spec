= Workflow Overview

explore → refine feature ticket → record change(s) → refine requirements and durable design → accept → apply → reconcile architecture → archive

Each refined change has a durable DSN design item before its temporary task list. ARC items belong to an arc42-aligned as-built baseline; ADRs record costly-to-reverse software architecture choices, while DEC items remain for domain and business decisions.
Only task checklists are temporary; archive retains design, architecture, and decision items.
