[#CHG-011, item, role=change, status=verified, title="Evaluate workflow skills with paired, repeatable scenarios"]
--
Rationale:: The skills guide exploration, traceability edits, and validation, but the repository has no repeatable way to check whether they deliver the expected behavior.
There is also no way to compare a run with the skill enabled against the same task without it.
The external skill-creator tooling provides useful evaluation and benchmark conventions, but it cannot run these skills in a reproducible, project-local setup.

Outcome:: Add a small evaluation runner to the repository.
Store one scenario file per skill and reuse the skill-creator eval schema where it fits.
Run each selected scenario against equivalent temporary project copies, once with the target skill enabled and once with it disabled.
Keep the transcripts and workspace-change summaries, then report deterministic expectation results, timing, and errors for both configurations.
Start with scenarios for explore, propose, and validate.
They cover read-only reasoning, traceability writes, and CLI validation.
Use the installed Claude Code CLI as the first execution adapter, with no added runtime dependency.

Out-of-scope:: Supporting other agent harnesses or model-provider APIs.
Building a hosted evaluation service, custom web review UI, automatic prompt optimizer, or general-purpose grading platform.
Treating automated text matches as a substitute for human review of nuanced reasoning.
Changing the durable traceability model to represent evaluation cases as graph items.
