[#CHG-009, item, role=change, status=proposed, title="Gate proposed requirements against implementation detail"]
--
Rationale:: The propose skill tells authors that requirements should state what the system does, not how it does it.
The rule is advisory, so requirements still include implementation details, such as a `trackerId` attribute in the change item block header.
The requirement guidance already has a "Solution prescription" flag list, but the skill does not apply it.

Outcome:: Before writing each requirement, the propose skill's Rules check its SHALL against the requirement guidance's "Solution prescription" list.
If a SHALL names a mechanism, rewrite it as an observable outcome and record the mechanism as a decision.
The skill refers to the existing flag list instead of duplicating it.

Out-of-scope:: Automatic enforcement through validation or linting.
The distinction is semantic and cannot be linted.
A new review skill.
Changes to the human acceptance gate or the archive cold reviewer.
