[#REQ-015, item, role=requirement, level=software, status=draft, title="Associate graph items with optional external identifiers"]
--
The system SHALL allow canonical graph items, including use cases, requirements, and changes, to carry optional scalar `externalId` metadata referencing an existing external item.

Items associated with the same external item MAY share an `externalId`. Items without an external association SHALL omit it. The reference SHALL remain metadata, not a traceability relation or graph item.
