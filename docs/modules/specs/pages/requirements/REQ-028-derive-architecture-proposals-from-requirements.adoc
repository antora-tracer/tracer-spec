[#REQ-028, item, role=requirement, level=component, status=approved, title="Require a durable design item for each change"]
--
Each refined implementation change SHALL have a durable, reviewable design item before its execution tasks are created.
The design SHALL explain how the relevant software requirements are addressed, identify affected architecture items, and record material alternatives and trade-offs.
If the change has no architecture impact, the design SHALL state that explicitly.
