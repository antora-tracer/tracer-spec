[#REQ-045, item, role=requirement, level=software, status=draft, title="Aggregate parent change actionability"]
--
WHEN an unclosed, unrejected change has one or more child changes linked to it by `refines` and the hierarchy is acyclic, the system SHALL report it as actionable exactly when every linked child change is actionable, applying the same rule recursively. A cycle produces a nonzero error without a status line.

Example: An unclosed parent whose children are all `refined` or `accepted` is reported with `actionable=true`; if any child is `proposed`, it is reported with `actionable=false`.
