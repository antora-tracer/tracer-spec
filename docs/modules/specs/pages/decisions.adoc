= Decisions
:traceability-links: true

Use `decision` items for domain and specification choices. Use `adr` items for costly-to-reverse software architecture choices; see xref:adrs.adoc[Architecture Decisions].

[source,asciidoc]
----
[#DEC-NNN, item, role=decision, status=proposed, title="<domain or specification choice>"]
--
Context:: Why this decision is needed.
Options:: Material alternatives and their advantages and disadvantages.
Decision:: What was decided.
Rationale:: Why the chosen option was selected.
Consequences:: What follows.

recorded_by:CHG-NNN[]
tracer:links[]
--
----

Decisions are grouped by status.
An `accepted` decision governs the current workflow; a `proposed` one is not yet in force.
