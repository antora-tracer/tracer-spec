[#REQ-069, item, role=requirement, level=product, status=approved, title="State one obligation per requirement"]
--
The system SHALL record each requirement with exactly one obligation, so that one pass/fail verdict decides it.

Obligations at different levels are recorded as a parent requirement and a refining child; obligations at the same level are separate items.
