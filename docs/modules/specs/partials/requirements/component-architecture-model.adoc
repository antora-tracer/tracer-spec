[#REQ-086, item, role=requirement, level=component, status=approved, title="Represent architectural elements as durable items"]
--
The workflow SHALL represent each independently meaningful architectural element as a durable, typed architecture item with a stable identifier.

Headings and explanatory prose do not require graph items.

refines:REQ-051[]

[#REQ-087, item, role=requirement, level=component, status=approved, title="Organize architecture items in an arc42-aligned baseline"]
--
The workflow SHALL organize and describe the architecture items in an arc42-aligned baseline that reflects the implemented architecture.
