= Design Concepts

[#DES-001, item, role=design_concept, status=accepted, title="Single traceable project knowledge base"]
--
Requirements, use cases, changes, ADRs, and design concepts are maintained as items in project-level Antora content.
This avoids a parallel specification hierarchy and makes the published documentation the primary review surface.

[#DES-002, item, role=design_concept, status=accepted, title="Temporary change execution plan"]
--
A change may have an ordinary AsciiDoc plan containing a generated and revisable task checklist.
The plan supports a gap between planning and execution without making tasks durable project artifacts.
